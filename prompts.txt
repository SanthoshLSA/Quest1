STEP 1 - Project Setup & GitHub
--------------------------------
Connect the GitHub repo https://github.com/SanthoshLSA/Quest1 and do the initial commit and push.


STEP 2 - Video Downloader
--------------------------
Build a module that takes any video URL, grabs the video and audio, and pulls out basic info like frame rate, total frames, video length, and resolution.


STEP 3 - Find the Spoken Line
------------------------------
Use Whisper to listen through the video audio and find exactly when a specific line of dialogue is spoken. Return the time and the frame number it lands on.


STEP 4 - Read Text from the Frame
-----------------------------------
Once we have the rough timestamp, look at the frames around it and use OCR to read any on-screen text. Find the exact frame where the dialogue appears visually.


STEP 5 - Tie It All Together
------------------------------
Build the main script that runs everything in order: download, listen, find, confirm, and save the matching frame as an image.


STEP 6 - Write the Docs
-------------------------
Write a clear README explaining how to run the tool, and an APPROACH document explaining how the whole thing works and why it was built this way.


STEP 7 - Web Dashboard
------------------------
Add a web interface where you paste a URL and a line of dialogue, hit go, and watch live progress updates as it searches. Show the result with the matching frame screenshot and a short video clip. Keep the design black and white, terminal style.
